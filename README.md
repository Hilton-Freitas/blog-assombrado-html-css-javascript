# Blog Assombrado — HTML, CSS e JavaScript

Esse projeto foi desenvolvido a partir de uma atividade prática de front-end com foco em propriedades de posicionamento no CSS. O objetivo foi transformar a página original em uma versão mais organizada e adequada para portfólio.

Veja funcionando: https://hilton-freitas.github.io/blog-assombrado-html-css-javascript/

Durante o desenvolvimento, foram aplicados:

- **HTML5 semântico**, com uso de `header`, `nav`, `main`, `section`, `article`, `footer`, `time` e textos alternativos nas imagens.
- **CSS3** para criação da identidade visual, organização dos conteúdos, cores, tipografia, espaçamentos, sombras e estados de interação.
- Propriedades de posicionamento como `relative`, `absolute`, `fixed` e `sticky`.
- Uso de `top`, `right`, `bottom`, `left` e `z-index` para controlar sobreposições e elementos fixos da interface.
- Títulos sobrepostos às imagens, exibidos com `hover` e transições de `opacity` e posição.
- Nuvem de tags com interação ao clique e comportamento fixo durante a rolagem da página.
- Botão de retorno ao topo com posicionamento fixo.
- Animações e interações com JavaScript, incluindo os personagens Boo e o controle da vinheta de abertura.
- **Flexbox, Grid e Media Queries** para adaptar o layout a telas menores.
- **Variáveis CSS** para facilitar a manutenção de cores e estilos.
- Boas práticas de acessibilidade, como textos alternativos, navegação identificada, foco visível e suporte à redução de animações.

Também criei páginas separadas para as seções de **UFOlogia**, **Fantasmas** e **Lendas**, formando uma navegação mais completa.

O projeto foi desenvolvido com **HTML, CSS e JavaScript**, com foco na prática de estruturação de páginas, estilização, responsividade, posicionamento de elementos e organização de código.
